# 🌱 SmartCrop – Smart Crop Recommendation System

A farmer-friendly web application that recommends suitable crops based on soil type, season, rainfall and water availability.

## 🌐 Live Demo

[Launch SmartCrop](https://smartcrop-ev3i.onrender.com)

## 📖 About the Project

SmartCrop is a software-based agricultural decision-support system developed as a first-year AI & ML engineering team project at SMVITM, Bantakal.

The application helps farmers make informed crop selection decisions without requiring IoT sensors or additional hardware.

## 🚀 Key Features

- 200-crop recommendation database
- Detailed crop cultivation guide
- Support for 31 Karnataka districts
- Rule-based crop recommendation algorithm
- Crop suitability scoring
- Profit and loss estimation
- Crop comparison
- Crop category and growing duration filters
- Seven-day weather forecast
- English, Kannada and Hindi language support
- Farming chatbot and voice assistant
- Kannada text-to-speech
- User login and registration
- Mobile-friendly interface

## ⚙️ How It Works

1. The farmer enters farm details.
2. The system compares inputs with crop requirements.
3. Suitable crops are ranked using rule-based scoring.
4. Estimated investment, income and profit are calculated.
5. Results are displayed in the selected language.
